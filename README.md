# YandexPracticum


Проект API для работы с мероприятими.
Реализованы методы для работы с мероприятими просмотр/срздание/изменение/удаление. 

- Для сборки проекта необходимо выполнить команду #dotnet build из корневой директории.
- Для запуска проекта необходимо перейти в папку ./EventsApi/ и выполнить команду #dotnet run
После запуска открыть браузер по адресу http://localhost:5091/swagger/index.html
- Для запуска тестов неободимо выполнить команду #dotnet test из корневой дирректории.

Добавлена функция фильтрация в метод /events по параметрам: title, from, to.
- поиск по названию (регистронезависимый, частичное совпадение);
- from (опциональный) — события, которые начинаются не раньше указанной даты;
- to (опциональный) — события, которые заканчиваются не позже указанной даты.

Расширен метод /events параметрами фильтраци для пагинации событий:
 - page (опциональный, c значением по умолчанию 1) — страница, которую необходимо вернуть;
 - pageSize (опциональный, со значением по умолчанию 10) — количество элементов на странице.

Добавлен глобальный фильтр необработанных исключений, возвращается единообразный JSON-ответ с информацией об ошибке.
Формат ответа:
{  
  "status": 200, //код статуса
  "detail": "сообщение" // сообшение об ошибке
}
